## About

I'm a B.Tech CSE (IoT & Cybersecurity) student and full-stack developer currently interning at **SKH Private Limited**, where I built a role-based Canteen Management System now running inside the company. This site is where I bring together that work, my AI/ML projects, and my research — built entirely from scratch, no template.

## Why this exists

 I wanted mine to actually demonstrate the kind of frontend work I can do: a custom 3D node-network hero (Three.js) built around my IoT specialization, scroll-based reveal animations, and a fully working contact form — no backend required to receive a message.

## Built with

- **HTML5 / CSS3** — hand-written, no framework, no build step
- **Vanilla JavaScript** — scroll reveals via `IntersectionObserver`, custom cursor, mobile nav
- **Three.js** — the rotating 3D node-network in the hero section
- **FormSubmit** — contact form delivery, zero backend
- Deployed on **Vercel**

## Structure

```
├── index.html      # all page content
├── style.css        # design system: colors, type, layout, animations
└── script.js        # 3D scene, scroll reveals, form handling
```

## Running locally

No install, no build step — it's plain HTML/CSS/JS.

```bash
git clone https://github.com/goldigd05/YOUR-REPO-NAME.git
cd YOUR-REPO-NAME
```

Then just open `index.html` in a browser, or serve it locally:

```bash
python -m http.server 8000
# visit http://localhost:8000
```
